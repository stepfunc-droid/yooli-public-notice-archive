# 有利网公示档案

范围：第295批至第200批，包含两端。只沿正文“推荐阅读”中标记为有利网严重失信借款人公示的链接抓取。

- `index.html`：离线浏览总入口。
- `list.md` / `list.json` / `urls.txt`：批次、发布日期、标题、原文链接、图片和抓取状态清单。
- `batch-XXXX/raw.html`：完整 HTTP 响应 HTML，保留原样。
- `batch-XXXX/index.html`：离线正文，包含全部正文图片，已抓取批次的推荐链接指向本地。
- `batch-XXXX/body.txt`：正文文本；图片以顺序编号占位。
- `batch-XXXX/metadata.json`：来源、抓取时间、推荐链接、图片来源、本地路径和 SHA-256。
- `assets/`：正文原始图片字节；优先下载 CDN `/0` 尺寸版本，失败则回退正文嵌入地址；每份图片均记录实际下载地址。
- `verification.json`：完整性结果。
- `archive_crawler.py`：可重复运行的抓取脚本，复用已有 HTML 和经过哈希校验的图片。

正文名单是图片，当前保存原始内容，尚未 OCR 或生成借款人统计表。保留原文的姓名、身份证、手机号掩码。动态评论、点赞等需要运行时接口的数据不属于本次静态正文归档；外部跳转目标（如 APP 下载页）仅保留链接。
