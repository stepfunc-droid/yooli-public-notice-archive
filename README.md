# 有利网公示档案

范围：第295批至第1批，包含两端。只沿正文“推荐阅读”中标记为有利网严重失信借款人公示的链接抓取。

- `index.html`：离线浏览总入口。
- `list.md` / `list.json` / `urls.txt`：批次、发布日期、标题、原文链接、图片和抓取状态清单。
- `batch-XXXX/raw.html`：完整 HTTP 响应 HTML，保留原样。
- `batch-XXXX/index.html`：离线正文，包含全部正文图片，已抓取批次的推荐链接指向本地。
- `batch-XXXX/body.txt`：正文文本；图片以顺序编号占位。
- `batch-XXXX/metadata.json`：来源、抓取时间、推荐链接、图片来源、本地路径和 SHA-256。
- `assets/`：正文原始图片字节；优先下载 CDN `/0` 尺寸版本，失败则回退正文嵌入地址；每份图片均记录实际下载地址。
- `verification.json`：完整性结果。
- `archive_crawler.py`：可重复运行的抓取脚本，复用已有 HTML 和经过哈希校验的图片。

正文名单是图片。已完成第1—295批OCR，正式CSV与预览入口见 `tables/index.html`；逐页数据、识别记录和校验报告保存在 `ocr/`。当前未给出跨批唯一人数或包括未知金额的精确总额。保留原文的姓名、身份证、手机号掩码。动态评论、点赞等需要运行时接口的数据不属于本次静态正文归档；外部跳转目标（如 APP 下载页）仅保留链接。

完整性校验脚本：`python3 archive_verify.py`。`runs/` 保留前一阶段清单、报告及历史工具；本次日志为 `crawl-to-first.log`。

OCR表格共621,462条原图记录，其中75条来自同批重复引用图片。第254批第298、327条原图金额显示为 `########`，保留未知空值。原文存在52个序号缺口，不据此补造记录。非金额字段的不确定识别保留复核标记。第35批一张无法解码的原始CDN响应已保留备份，并以可正常解码的嵌入图片响应修复。
