# 公示 OCR 表格

每批一份 UTF-8 BOM CSV，可用 Excel 或 Python 读取。列包括原表字段、批次、发布日期、金额整数分、校验状态及原图定位。第214批原图缺少借款期限，留空并标明原表未提供。

第254批第298、327条原图金额为 `########`，金额值留空，不能视作0或声称已得到包括它们的精确总金额。原文还存在重复图片和序号缺口，见 `../ocr/publication-anomalies.json`。

金额计算应使用 `金额_分`，避免浮点误差。人数首先是公示记录数；身份证和姓名有掩码，不能据此保证跨批唯一人数。`同批重复原图记录` 标记原文重复引用同一页的第二次及以后记录，后续统计可明确选择是否排除；`图像跨批共用` 标记原文复用同一图片的情况，保留全部发布记录。OCR 不是人工逐行校对；`需复核字段` 和 `金额校验状态` 说明识别异常或双引擎核对结果。

当前表格生成过程和异常结果见 `batch-list.json` 及 `../ocr/review-issues.json.gz`。原始网页和图片保留在父目录。
